# Transfer-Learning-for-Image-Classification

Developed an image classification system using transfer learning to distinguish six different image categories. 
Leveraged pre-trained deep learning models, including ResNet50, ResNet101, EfficientNetB0, and VGG16, as feature extractors, training only the final fully connected layer while freezing earlier layers. 
Applied data augmentation techniques such as cropping, zooming, rotation, flipping, and contrast adjustments to enhance model generalization. 
Optimized the network using ReLU activations, L2 regularization, batch normalization, dropout, and the ADAM optimizer. 
Evaluated model performance using Precision, Recall, AUC, and F1-score across training, validation, and test sets, identifying the best-performing architecture for image classification.
